# greghomstad.com

Personal portfolio for Greg Homstad — Technical Product Owner specializing in enterprise systems, SAP S/4HANA, and data reconciliation.

**Live site:** [greghomstad.com](https://greghomstad.com)

## Tech Stack

- React 19 + TypeScript
- Vite 7
- Tailwind CSS v4
- Deployed on Vercel

## Development

```bash
npm install
npm run dev      # Dev server
npm run build    # Type-check + production build
npm run lint     # ESLint
```
